# Pre-Entrega 1: Simulador de Compra en Cuotas

Primera pre-entrega del curso de **JavaScript** de la carrera Desarrollo FullStack en Coderhouse (Módulo 1: Primeros pasos con JavaScript).

## Descripción

Programa que le pide datos al usuario, calcula el costo de una compra en cuotas y muestra un resumen.

1. **Solicita** nombre, año de nacimiento, producto, precio y cantidad de cuotas con `prompt()`.
2. **Procesa** los datos:
   - convierte los números con `parseInt()` y `parseFloat()`
   - calcula la edad, el recargo (5% por cuota), el precio final y el valor de cada cuota
   - arma un mensaje concatenando strings con las variables
3. **Muestra** el resultado con `alert()` y `console.log()`.

## Estructura

```
PE1/

```

El script está vinculado en el `<head>` del `index.html` con el atributo `defer`.

## Cómo usarlo

1. Descargá o cloná el repositorio.
2. Abrí `index.html` en el navegador.
3. Respondé las preguntas.
4. Mirá el resumen en la alerta y en la consola (F12 → Consola).

## Tecnologías

- HTML5
- JavaScript (`const` / `let`, `prompt`, `parseInt`, `parseFloat`, `console.log`, `alert`)
